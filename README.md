# City Drive – multiplayer server

## הרצה מקומית (לבדיקה)
    npm install
    node server.js          # http://localhost:8080
פתח בשני טאבים; בטאב אחד "Create room", בשני הדבק את הלינק.

## פריסה חינמית ב-Render (3 צעדים)
1. העלה את התיקייה הזו ל-GitHub (server.js, package.json, public/index.html).
2. ב-render.com: New → Web Service → בחר את הריפו. Build: `npm install`, Start: `node server.js`.
3. קבל כתובת https://xxx.onrender.com – היא גם המשחק וגם השרת. לינק/QR ההזמנה נוצרים אוטומטית.

הערה: בתוכנית החינמית השרת "ישן" אחרי כמה דקות ללא שימוש; פתיחה ראשונה לוקחת ~30 שניות.
